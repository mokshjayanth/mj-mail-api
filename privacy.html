Privacy policy

Last updated: 16 October 2026

mj-mail-api is a personal tool used only by its owner, with the owner's own Google accounts. It is not offered to anyone else.

What it accesses

With the permissions granted at sign-in, it reads Gmail messages and labels, saves drafts, changes labels, and reads and adds Google Calendar events. Each account is granted only the permissions it needs.

How data is used and stored

  • Data is used only to help the owner manage their own mail and calendar.
  • Sign-in tokens are stored only on the owner's private server, readable only by the owner.
  • Mail and calendar content is fetched when needed and not stored by this tool. To answer the owner's requests, content may be passed to the owner's AI assistant (Anthropic's Claude).
  • Data is not sold, shared with other parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
